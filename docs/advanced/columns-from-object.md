# Extract columns from an object

These functions take the columns out of a table, a view or any object that has columns, keeping their types. They answer questions like "select all the columns of this table except these two", or "which columns of this table can I write?". The result can go to a `select` or your own code.

They are in `ts-sql-query/extras/utils`, and also in the root `ts-sql-query`. All of them receive the object as the first argument and, optionally, an array with the names of the properties to leave out as the second one.

| Which columns | The columns, as an object | Their names, as an array |
|---|---|---|
| All of them | `extractColumnsFrom` | `extractColumnNamesFrom` |
| Those you can write in an insert or an update | `extractWritableColumnsFrom` | `extractWritableColumnNamesFrom` |
| The primary key | `extractIdColumnsFrom` | `extractIdColumnNamesFrom` |
| The primary key, if it's autogenerated | `extractAutogeneratedIdColumnsFrom` | `extractAutogeneratedIdColumnNamesFrom` |
| The primary key, if your code provides its value | `extractProvidedIdColumnsFrom` | `extractProvidedIdColumnNamesFrom` |

`extractWritableShapeFrom` gives a [shape](../queries/shapes.md) with the writable columns. The [utility types](utility-types.md#columns) give the same names as types.

## Select all the columns of a table

To select all the columns of a table or a view, pass it to `select`. The SQL lists each column by its name; it isn't a `select *`:

<!-- doc-code-snippet-result: { id: 9, firstName: 'John', lastName: 'Smith', name: 'John Smith', companyId: 1 } -->
```ts
const customer = await connection.selectFrom(tCustomer)
    .select(tCustomer)
    .where(tCustomer.id.equals(9))
    .executeSelectOne();
```

The executed query is:

=== "MariaDB"
    ```mariadb
    select 
        id as id, 
        first_name as firstName, 
        last_name as lastName, 
        birthday as birthday, 
        company_id as companyId, 
        concat(first_name, ?, last_name) as name, 
        calculateAge(birthday) as age 
    from customer 
    where id = ?
    ```
=== "MySQL"
    ```mysql
    select 
        id as id, 
        first_name as firstName, 
        last_name as lastName, 
        birthday as birthday, 
        company_id as companyId, 
        concat(first_name, ?, last_name) as `name`, 
        calculateAge(birthday) as age 
    from customer 
    where id = ?
    ```
=== "Oracle"
    ```oracle
    select 
        id as "id", 
        first_name as "firstName", 
        last_name as "lastName", 
        birthday as "birthday", 
        company_id as "companyId", 
        first_name || :0 || last_name as "name", 
        calculateAge(birthday) as "age" 
    from customer 
    where id = :1
    ```
===+ "PostgreSQL"
    ```postgresql
    select 
        id as id, 
        first_name as "firstName", 
        last_name as "lastName", 
        birthday as birthday, 
        company_id as "companyId", 
        first_name || $1 || last_name as name, 
        calculateAge(birthday) as age 
    from customer 
    where id = $2
    ```
=== "SQLite"
    ```sqlite
    select 
        id as id, 
        first_name as firstName, 
        last_name as lastName, 
        birthday as birthday, 
        company_id as companyId, 
        first_name || ?1 || last_name as name, 
        calculateAge(birthday) as age 
    from customer 
    where id = ?2
    ```
=== "SQL Server"
    ```sqlserver
    select 
        id as id, 
        first_name as firstName, 
        last_name as lastName, 
        birthday as birthday, 
        company_id as companyId, 
        first_name + @0 + last_name as name, 
        calculateAge(birthday) as age 
    from customer 
    where id = @1
    ```

The parameters are: `[ ' ', 9 ]`

It's the same as `.select(extractColumnsFrom(tCustomer))`. Use `extractColumnsFrom` when you want to leave some out. A table can also be a property of the select, like `{ customer: tCustomer }`, which gives a nested object: see [Complex projections](../queries/complex-projections.md).

## Extract columns

`extractColumnsFrom` returns an object with all the columns of the object you give it, ready to use in a select:

```ts
import { extractColumnsFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

const selectAll = connection.selectFrom(tCustomer)
    .select(extractColumnsFrom(tCustomer))
    .where(tCustomer.id.equals(9))
    .executeSelectOne();
```

## Extract writable columns

`extractWritableColumnsFrom` works like `extractColumnsFrom`, but it returns only the columns you can use in an insert or an update: it leaves out computed and virtual columns, and properties that are expressions, like `name` here.

```ts
import { extractWritableColumnsFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

const selectAll = connection.selectFrom(tCustomer)
    .select(extractWritableColumnsFrom(tCustomer))
    .where(tCustomer.id.equals(9))
    .executeSelectOne();
```

The executed query is:

=== "MariaDB"
    ```mariadb
    select 
        id as id, 
        first_name as firstName, 
        last_name as lastName, 
        birthday as birthday, 
        company_id as companyId 
    from customer 
    where id = ?
    ```

```ts
import { extractWritableColumnNamesFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

```

## Extract writable shape

`extractWritableShapeFrom` returns a [shape](../queries/shapes.md) for an insert or an update where each property of the values has the name of its column, like `{ firstName: 'firstName' }`. It's useful to limit what is written from an object that has more properties: see [Insert and update with a shape](../queries/shapes.md).

```ts
import { extractWritableShapeFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

const tCustomerWritableShape = extractWritableShapeFrom(tCustomer);
```

## Extract id columns

`extractIdColumnsFrom` returns only the columns of the primary key.

```ts
import { extractIdColumnsFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

const idColumns = extractIdColumnsFrom(tCustomer);
```

To get an array with their names, use `extractIdColumnNamesFrom`:

```ts
import { extractIdColumnNamesFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

const tCustomerIdColumnNames = extractIdColumnNamesFrom(tCustomer);
```

## Extract autogenerated id columns

`extractAutogeneratedIdColumnsFrom` returns only the columns of the primary key whose value the database generates.

```ts
import { extractAutogeneratedIdColumnsFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

const autogeneratedIdColumns = extractAutogeneratedIdColumnsFrom(tCustomer);
```

To get an array with their names, use `extractAutogeneratedIdColumnNamesFrom`:

```ts
import { extractAutogeneratedIdColumnNamesFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

const tCustomerAutogeneratedIdColumnNames = extractAutogeneratedIdColumnNamesFrom(tCustomer);
```

## Extract provided id columns

`extractProvidedIdColumnsFrom` returns only the columns of the primary key that aren't autogenerated, so your code provides their value. In the `tCustomer` of these examples the primary key is autogenerated, so the result is empty.

```ts
import { extractProvidedIdColumnsFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

const providedIdColumns = extractProvidedIdColumnsFrom(tCustomer);
```

To get an array with their names, use `extractProvidedIdColumnNamesFrom`:

```ts
import { extractProvidedIdColumnNamesFrom } from "ts-sql-query" // or "ts-sql-query/extras/utils";

const tCustomerProvidedIdColumnNames = extractProvidedIdColumnNamesFrom(tCustomer);
```

## Groups of columns

When the object has [groups of columns](../configuration/mapping.md#grouping-columns), every function on this page keeps them: the functions that return columns or a shape return the group with only the columns that apply, and leave it out if it has none; the functions that return names give the path of each column, like `'ubication.latitude'`. In the list of columns to exclude, `'ubication.latitude'` leaves out that column and `'ubication'` the whole group. Anything else in the object that is not a column is left out, also an object that has no columns.
